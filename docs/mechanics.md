# Игрок

## Базовые характеристики (MVP)

На первом этапе разработки каждый игрок обладает следующими характеристиками:

### Общие
- Имя, Фамилия
- Ник - игровое имя игрока
- Возраст - отображает сколько лет игроку.
- Зарплата - ежемесячные траты на игрока

### Игровые навыки
- Общий аим — отражает общий уровень стрельбы игрока.
- Аим с пистолетами — эффективность игрока в пистолетных раундах.
- Макро-навыки — понимание игры, принятие стратегических решений и работа с информацией.
- Микро-навыки — скорость и качество выполнения индивидуальных игровых действий.

### Психологические характеристики
- Стабильность — вероятность показывать результаты, близкие к своему реальному уровню.
- Стрессоустойчивость — способность сохранять эффективность в важных матчах и напряжённых ситуациях.

### Социальные характеристики
- Медийность — влияет на популярность игрока, привлечение аудитории и коммерческую ценность.
- Дружелюбие — влияет на атмосферу внутри коллектива и формирование командной синергии.

### Планируемые характеристики

Могут быть добавлены на более поздних этапах разработки:
- Навык игры с AWP.
- Владение гранатами (Utility).
- Игровая роль.
- Предпочитаемые позиции на картах.
- Дополнительные индивидуальные характеристики.

# Команда

## Базовые характеристики (MVP)

### Состав
Текущий ростер команды

### Средний уровень состава
Сводный показатель силы команды, рассчитываемый на основе характеристик игроков.

### Синергия
Показатель сыгранности состава и качества взаимодействия между игроками.

### Подготовка карт
Для каждой карты хранится отдельный показатель уровня игры команды.

### Влияние тренера
Бонусы и модификаторы, получаемые командой благодаря тренерскому штабу.

# Симуляция матчей

## Базовые параметры (MVP)

### Уровень команд
Основной фактор определения силы участников матча.

### Коэффициент случайности
Позволяет моделировать апсеты и непредсказуемость реального киберспорта.

### Карты
При расчёте результата учитывается уровень подготовки команды на выбранной карте.

## Планируемое развитие системы

- Учёт длительности совместной игры игроков.
- Учёт знания сильных и слабых сторон партнёров по команде.
- Личные противостояния игроков на одинаковых позициях.
- Более глубокая симуляция отдельных игровых ситуаций.

# Игровой цикл

Игрок управляет организацией.

Основное действие игрока — продвижение времени.

Каждый игровой день выполняется:

1. Обновление даты.
2. Проверка календаря турниров.
3. Проведение матчей.
4. Обновление активных турниров.
5. Обработка контрактов.
6. Обработка финансов.
7. Генерация новостей.

Все игровые системы работают через игровой цикл и не запускаются вручную.
