# Roadmap

## Назначение файла

В этом файле хранится план разработки проекта.

Здесь описывается:
- Что уже сделано.
- Что будет сделано дальше.
- Какие функции входят в каждую версию игры.

Этот файл нужен для планирования разработки, а не для описания игровых механик.

---

## v0.1 — Первый игровой прототип

### Добавлено
- Система игроков
- Система тренеров
- Система команд
- Система матчей
- Симуляция матчей на основе силы команд
- Игровой мир (World)
- Симуляция игрового мира
- Фабрика тестовых команд

### Реализованные характеристики игроков
- Общая стрельба
- Стрельба с пистолетов
- Макроигра
- Микроигра
- Стабильность
- Стрессоустойчивость
- Медийность
- Уровень командного взаимодействия

### Реализованные характеристики тренеров
- Макроигра
- Стабильность
- Уровень командного взаимодействия

### Текущее состояние проекта
На данный момент игра позволяет создавать команды, рассчитывать их силу, проводить матчи и выполнять базовую симуляцию игрового мира.
